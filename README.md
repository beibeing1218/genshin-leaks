# 原神內鬼情報站

自動彙整原神內鬼（爆料）消息，產生一頁看板。全程不呼叫 AI 模型、不消耗 token，只用 Python 標準庫。

| 來源 | 內容 |
|---|---|
| 巴哈姆特原神板「內鬼資訊」 | 最近活躍的內鬼消息串，讀最後兩頁的每一樓（文字、圖片、X 連結） |
| Reddit r/Genshin_Impact_Leaks | 全球內鬼消息集散地，標題翻成中文，`via 某某` 會標成爆料者 |
| HoYoLAB 官方資訊（繁中） | 拿來對照哪些內鬼消息已被官方證實 |
| 外媒報導（Google News） | Sportskeeda 等媒體的爆料整理文 |

- 本機版：雙擊桌面「原神內鬼情報站」捷徑（或 `python leaks.py open`）。資料超過 1 小時會自動更新，網頁上的「立即更新」可隨時手動抓。
- 側欄「爆料者排行」統計最近被引用最多的爆料者，點名字可以只看他的消息。
- 來源設定在 `leaks.py` 最上方；遊戲譯名修正在 `ZH_FIX`、`ZH_NAMES`。
